# Daily Verse 封面方向 — 第二批（60 天，120 条，七语言共用）

> 封面是**早/晚两个轮换池**的背景图，不是一节一图。风格锚定现行 `follow_him`
> 日/夜双图：写实柔光、大面积留白、无人物特写正脸、无文字。
> 本批跨度 60 天，比试点批长六倍，**两池各需 6 张新图**（试点批是各 4 张）。
>
> ⚠️ **编号仍待确认（与试点批同一个待办）**：下方沿用试点批的顺推逻辑，
> 从 `morning-08` / `evening-08` 起编。试点批用掉了 04–07，本批接 08–13。
> **工程侧确认现行池实际尾号后我一次改齐** —— 编号撞车会让新图覆盖掉在用的旧图。
>
> 通用约束（每张都适用，不再逐条重复）：
> - 无文字、无 logo、无正脸人物、无宗教符号特写（十字架剪影可，须远景）
> - 同图会被裁切进 **4×2 桌面小组件**——主体压在**中心安全区**内，四边留出裁切余量
> - 压缩后 **≤ 300KB（webp）**
> - 玫红是 UI 强调色，背景不得出现玫红大色块，避免与前景控件抢视线
> - **七语言共用同一批图**，所以画面里不能出现任何语言的文字、任何地域性极强的建筑或服饰

**本批主题分布**（据 120 条实际选经，供配图取向参考）：
早间集中在 faith / courage / strength / hope / guidance；
晚间集中在 love / peace / forgiveness / presence / confession。
晚间池明显更"关系向"，配图应比试点批更暖、更近，少用空旷远景。

## 早间池（morning-08 … morning-13）

### morning-08
- 气质：一天刚被交到手里，安静但已醒
- 画面：清晨的窗内俯视，一杯水与一只空掌心并置在木桌面；光从左侧低角度进来
- 构图：桌面占下三分之一，**上方 2/3 留净空**；掌心压在中心安全区偏左
- 色彩：暖白 + 浅木 + 一线晨橙；整体高明度低饱和
- 用途备注：对应 provision / thanksgiving 类。**掌心不得入镜到腕以上**，避免出现可辨识的人；指甲、首饰、纹身一律不要

### morning-09
- 气质：还没看见路，但已经可以迈一步
- 画面：晨雾里的石阶，只有最近的两三级清晰，往上化进雾里
- 构图：石阶自下缘偏右入画，斜向左上；**上方与左侧大片留空**
- 色彩：雾青灰 + 湿石的冷褐 + 尽头一点未成形的暖光
- 用途备注：对应 guidance / faith 类，尤其诗 119:105「脚前的灯」。**不要拍成登山励志图**——雾要真的挡住视线，看得见全程就毁了这张图的意思

### morning-10
- 气质：力气不是自己攒的
- 画面：逆光下的一株野草，被风压弯又没断；背景是化开的旷野与远处地平线
- 构图：草茎压在中心安全区，**四周留净空**；地平线极低
- 色彩：金褐 + 逆光的白 + 极浅的天青
- 用途备注：对应 strength / endurance 类（赛 40:29、林后 4:16）。**弯而不折是全部重点**——不要拍成挺立的草，也不要拍成折断的

### morning-11
- 气质：日常的、可以直接开工的一天
- 画面：晨光里的书桌一角：合着的笔记本、一支笔、一副摘下的眼镜；窗外只见虚化绿意
- 构图：器物集中在右下，**左上留大片净空**
- 色彩：奶白 + 浅灰 + 一点点叶绿的反光
- 用途备注：对应 work 类（西 3:23、弗 5:16、林前 15:58）——这批有 6 条职场情感域条目会落在这张上。**笔记本与眼镜不能有品牌标识**，笔记本必须合着（摊开就会有文字问题）

### morning-12
- 气质：光一点一点亮起来，不是一下子
- 画面：一整片天空的渐变，从近地平线的暖金过渡到高处的浅青；地面只留极窄一条剪影
- 构图：几乎全是天空，**任何位置都可叠字**；剪影压在下缘十分之一
- 色彩：暖金 → 蜜色 → 浅青，过渡要柔，不能有分层带
- 用途备注：对应 hope / growth 类（箴 4:18「越照越明」）。**渐变压缩后极易出色带**——出图时给天空加一点噪点抖动，否则 webp 会糊成台阶

### morning-13
- 气质：被差出去，往人那里走
- 画面：一条穿过田野的小路，晨光从右后方来，路上有两道并行的车辙
- 构图：路自下缘中央入画，向右上收；**上方留净空**
- 色彩：晨绿 + 土黄 + 暖白光晕
- 用途备注：对应 peacemaking / service 类（太 5:9、来 12:14）。**两道车辙是刻意的**——暗示同行，但不要出现人物

## 晚间池（evening-08 … evening-13）

### evening-08
- 气质：一天结束，手可以松开了
- 画面：夜里的室内，一盏暖灯下的空椅与搭在椅背的一件外套
- 构图：椅子压在中心安全区偏右，**左上留净空**
- 色彩：深棕 + 暖橘的灯光 + 大面积的暗；对比不要拉太开
- 用途备注：对应 rest / release 类（太 11:28、彼前 5:7）。**外套要有真实的褶皱和垂坠感**——摆得太整齐就没有"卸下"的意思了

### evening-09
- 气质：被听见，而不是被评估
- 画面：夜窗内侧，玻璃上有呼吸的雾气与一道未擦净的水痕；窗外是化开的城市灯点
- 构图：窗框把画面切开，**右上留净空**
- 色彩：深靛蓝 + 窗外暖黄灯点 + 玻璃上的冷白反光
- 用途备注：对应 being heard / lament 类（王下 20:5「我看见你的眼泪」、诗 42:11）。**水痕不能拍成刻意的心形或文字**，就是一道普通的痕

### evening-10
- 气质：两个人之间的事，终于放下了
- 画面：夜色里的一张餐桌，两只杯子并排，其中一只已经空了；灯光从上方压下来
- 构图：两杯压在中心安全区，**上方与四周留余量**
- 色彩：暖褐 + 烛光橘 + 边缘暗下去的深色
- 用途备注：对应 forgiveness / relationships 类（太 6:14、弗 4:32、箴 17:9）——这批有 6 条家庭关系情感域条目落在这里。**两只杯子必须不一样**（不同高度或不同色），一模一样会读成"合一"而不是"和好"

### evening-11
- 气质：安稳到可以真的睡着
- 画面：夜里的床边一角：叠好的薄毯、一只空的水杯、窗外一线月光
- 构图：器物压在下三分之一偏左，**上方 2/3 留净空**
- 色彩：月白 + 灰蓝 + 一点点暖色的床品；整体冷调，靠布料的暖色回一点温度
- 用途备注：对应 peace / sleep 类（诗 4:9、诗 46:11、西 3:15）。**不要出现床本身或任何寝具的凌乱面**——这张要读成安稳，不是疲惫

### evening-12
- 气质：不是一个人在黑里
- 画面：夜间的窗，屋内暖光透出去，屋外是安静的雪地或草地；只有一扇窗亮着
- 构图：亮窗压在中心安全区偏下，**上方大片夜空留净空**
- 色彩：深夜蓝 + 一格暖黄 + 极浅的地面反光
- 用途备注：对应 presence / community 类（太 18:20「两三个人」、徒 16:25 半夜唱诗）。**只亮一扇窗**——亮一排就变成社区图，失去"两三个人"的意思

### evening-13
- 气质：爱是最后留下的那一样
- 画面：夜里桌上一束将谢未谢的花，花瓣掉了一两片在桌面；侧后方一点暖光
- 构图：花束压在右侧中心安全区，**左侧留净空**
- 色彩：暗绿 + 褪色的浅粉白 + 暖褐；**避开玫红**（UI 强调色）
- 用途备注：对应 love 类（林前 13:4、13:13、西 3:14、约 15:13）——晚间池 love 有 6 条，是最大的一组。**将谢未谢是重点**：完全新鲜就变成祝贺图，完全枯萎就变成哀悼图

## 给工程侧的两个提示

1. **早晚两池的冷暖分工要守住**：早间整体高明度、暖光为主；晚间整体低明度、深蓝/深褐为底加一点暖光源。用户一天看两次，色温差是最直接的"现在是早/晚"信号，比任何文案都快。
2. **本批 12 张里有 5 张是室内器物图**（morning-08/11、evening-08/10/11/13），比试点批比例高。这是刻意的：这批 24 条情感域条目大量落在职场、家庭、感情场景，旷野远景撑不住那种具体的日常感。但器物图在小组件尺寸下更容易糊，**出图时按 4×2 小组件先看一遍再定稿**。
