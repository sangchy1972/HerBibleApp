## 一、四个语种是怎么写出来的

按你定的规则：**跟随已审核的英文语气直接用母语写**；**但如果本地圣经版本的这一节与 KJV 有实质差异，就按本地版本、依我们的规则重写这一条**。

不是翻译。四个语种各自是母语级重写，每条都配了同一条的英文母版、同一个 `structure`、同一个长度档位。共 29 条命中「本地版本有实质差异」，逐条按本地版本重建了论证（清单见第三节）。

**七语言共享字段逐字对齐**：`id` / `day` / `segment` / `reference` / `mood_tags` / `special_occasion` / `devotional.structure` / `exegesis.verse_category` / `niv_word_count` 全部从 `verses_en.json` 读取写入，保证 byte 级一致，不会出现对不上的情况。

## 三、29 条本地版本差异，逐条怎么处理的

英文稿的论证若建立在 KJV 特有的词上，而本地译本没有那个词，照搬就会说不通。这类条目我按本地版本重写。

**中文（和合本）4 条**

| 条目 | 差异 | 处理 |
| --- | --- | --- |
| 诗 46:10 | 和合本「你们要休息」；KJV「Be still」（松手） | 中文版换成「休息」立论 |
| 罗 11:36 | 和合本「本于他，倚靠他，归于他」 | 用和合本的三个介词 |
| 西 3:15 | 和合本「基督的平安」；KJV「the peace of God」 | 写「基督的平安」 |
| 约壹 4:19 | 和合本「我们爱」（无宾语） | 不写成「我们爱他」 |

**西班牙语（Reina-Valera 1909）12 条** — 其中 3 条整段重建：

- 箴 27:19：RV1909 没有「水中照脸」的镜像意象，英文稿整段建立在「古人以静水为镜」上 → 改从「心与心相对」立论
- 箴 11:25：RV1909 用「使人满足」不是「浇灌」→ 换掉整个浇灌意象
- 诗 91:1：RV1909 作「庇护所」不是「隐密处」→ 从「庇护」而非「不被看见」立论

其余 9 条属用词层面：诗 73:26 用「磐石」不用「力量」、提后 1:7 用 templanza（节制）不用 sound mind、书 1:9 是陈述句不是反问句、可 11:24 是将来式、罗 12:2 用 reformaos / siglo、弥 7:18 作「忘记罪」、出 33:14 的 rostro（脸）反而比 KJV 更贴希伯来原文可直接用。

**葡萄牙语（Almeida）13 条** — 其中 3 条整段重建：

- 出 33:14：葡语只作「我必亲自与你同去」，没有「同在／面」这个词 → 改从「亲自」立论，希伯来「我的脸」降为 context_note 背景
- 弗 5:16：葡语译成「善用每个机会」，市场「买回」的动词整个不见 → 改从 kairos（机会窗口）立论
- 赛 26:3：葡语没有 KJV「十分／完全」的强调 → 不押 shalom shalom 的重复

其余 10 条属用词层面：林前 6:19 用 santuário（圣所）不用 templo、提后 1:7 用 covardia / moderação、诗 42:11 作「我的帮助」、箴 11:25 作「必得亨通」、可 9:23 从批判文本句式不同、约壹 4:19 同中文无宾语。

## 四、🔴 交付前必须知道的三件事

### 1. `translations.<lang>.modern.text` 全部留空

四个语种的现代译本（当代译本 / NVI / NVI-PT）受版权保护，§4b 只给了 traditional 的语料通道，**没有可取用的持牌来源**。凭记忆重建 480 条受版权译本既不可靠，也不适合进产品，所以我留空并在每个文件的 `meta.pending` 里标了出来：

```json
"pending": ["translations.es.modern.text — awaiting licensed source"]
```

这与试点批的做法不同（试点批我重建了 70 条并做了标注）。**这一栏必须由工程侧从持牌来源回填后才能上线。** traditional 一栏不受影响 —— 四个语种共 480 条全部逐字取自语料库。

英文稿的 `niv_primary` / `translations.en.modern` 仍是试点批同一个问题，同样待正源替换。

### 2. 语料库有 9 处数据缺陷，我一律照抄没改（§4 规则 4）

这些是语料库本身的问题，改在内容侧会导致每日经文与整章正文不一致。**必须转工程侧在语料库里修**：

| 语种 | 节 | 问题 | 影响 |
| --- | --- | --- | --- |
| es | 2 代 7:14 | 存的是 `ni nombre`，应为 `mi nombre` | 🔴 **语义被否定** |
| es | 诗 119:105 | 开头嵌了离合诗标记 `NUN.` | 显示时会多一个词 |
| pt | 林前 15:57 | `graça a Deus`，应为 `graças a Deus` | 🔴 **句子方向写反** |
| pt | 赛 25:1 | 开头是 `ç`，应为 `Ó` | 🔴 **编码损坏** |
| pt | 太 11:28 | `estai`，应为 `estais` | 错字 |
| pt | 西 3:14 | `revestí-vos` 重音位置错 | 错字 |
| pt | 约 15:16 | 缺一个逗号 | 标点 |
| pt | 箴 17:9 | `afastam`，应为 `afasta` | 单复数不一致 |
| pt | 哀 3:23 | 是小写句子残片，承接 22 节 | 🔴 **单独显示不成句** |

前四条和最后一条我建议优先修。写作上我做了规避：**正文一律不引用这些出问题的半句**，pt 哀 3:23 的 context_note 第一句就说明这节承接上一节。

另：语料库 en 版对 YHWH 一律用 `Lord`（非 KJV 传统的 `LORD`），已在上一份说明里写过，这是工程侧决定。

### 3. 诗篇编号：这四个语种全部对齐，法德两语确认要位移

16 条诗篇里有 11 条希伯来原文带题记（superscription）。我逐语言实测：

- **zh-Hans / zh-Hant / es / pt：11 条全部与 KJV 编号一致**，本次交付无位移风险。
  - es 的机制是把题记并进第 1 节：诗 46:1 = 「Al Músico principal… DIOS es nuestro amparo」，所以不产生位移
  - pt 的机制是不收题记：诗 46:1 直接是「Deus é o nosso refúgio」
- **fr（Segond 1910）/ de（Luther 1912）：各有 5 条位移。** 长的音乐指示（「Au chef des chantres… Sur alamoth」「…vorzusingen」）单独算第 1 节，整篇往后挪一节：

  | KJV | fr / de |
  | --- | --- |
  | 诗 4:8 | 4:9 |
  | 诗 20:4 | 20:5 |
  | 诗 42:11 | 42:12 |
  | 诗 46:10 | 46:11 |
  | 诗 56:3 | 56:4 |

  按你的决定，第二波这 5 条走 **`verse_local` 平级字段**，`reference` 保持七语言 byte 一致，对齐校验器照常通过。这 5 条的法德原文我在审计时已取到，第二波直接可用。

短题记（「Salmo de David」「Ein Psalm Davids」）会并进第 1 节和正文一起，不产生位移 —— 这就是为什么只有 5 条中招而不是 11 条。
