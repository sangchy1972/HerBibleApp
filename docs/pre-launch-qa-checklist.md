# Her Bible — 上线前回归测试清单

> 覆盖本轮所有改动。**重点在红米 / 小米(MIUI)/ 三星(OneUI)真机上逐项过**——这些机型是之前出问题最多的。
> 测试包必须是**全新构建的 AAB / dev build**(下面带 🔴 的项是原生改动,JS 热更新看不到,必须重新构建)。

---

## 0. 测试前准备
- [ ] 用**新构建**的包(包含 pager-view、splash 颜色、通知图标、广告单元等原生改动)。
- [ ] 至少 1 台红米 / 小米 + 1 台三星 + 1 台其他安卓;有条件加 1 台 iOS。
- [ ] 准备"差网"场景:开飞行模式 / 弱网 / 关后台数据,验证容错。

---

## 1. 冷启动 / 启动页 🔴(splash 颜色 + 两段式 loading)
- [ ] 杀进程冷启动:**第一帧就是粉色**,**全程无白屏闪一下**。
- [ ] 先显示**粉色 + Her Bible logo** 屏(约 2 秒),logo 居中。
- [ ] 再交叉淡入**经文配图屏**;经文/金句**不会在出现后又跳一下**。
- [ ] 经文屏停留 ≥3 秒;**慢机型会多等**,直到主界面经文/祷文就绪才进 app(进去首页**不应再补内容/闪一下**)。
- [ ] "Her Bible" 文案为 Lora 600(粉屏 + 配图屏底部)。

## 2. 祈祷流程滚动 🔴(react-native-pager-view)
- [ ] **红米/小米/三星**上:经文 → Reflection → Today's Practice → Closing Prayer **逐页都能顺畅竖滑**。
- [ ] **Reflection 长文滑到底,能顺利翻到下一页**(之前卡死的核心问题)。
- [ ] Closing Prayer 能滑到底点到 **Amen**。
- [ ] **全程开着人声朗读**时再滑一遍:**不卡顿、不掉帧、翻页正常**(之前朗读会让滚动一卡一卡)。
- [ ] 每页标题滑入动画正常;翻页不串动、不空白。

## 3. 人声高亮(时间戳)
- [ ] 开朗读,**每句话随声音逐句高亮**,跟得上节奏。
- [ ] **差网 / 离线**再测一遍:高亮**依然出现**(时间戳已随音频缓存到本地)。
- [ ] 切到下一天的经文,高亮仍正常。

## 4. 评论弹窗(本轮修复)
- [ ] 首页经文卡点**评论图标(数字那个)→ 弹窗正常弹出**(之前在新架构 Modal 里弹不出来)。
- [ ] 点赞心心有反馈动画;点背景/关闭能收起。
- [ ] 顺手验证同卡的**点赞 / 分享 / More** 都正常。

## 5. 通知 🔴(图标 + 文案)
- [ ] 触发提醒,通知**小图标是干净的白色剪影 + 品牌粉底**(不再是糊成一团的方块)。
- [ ] 标题/正文正常(如 "Quiet hours" / "Tonight's verse is waiting for you." 属正常随机变体)。
- [ ] 点 **Amen** 动作 / 点通知能正确深链进 app。
- [ ] 早晚提醒按设置的时间到达。

## 6. 计划详情页
- [ ] **"Start Reading Plan" 按钮在 Daily Plan 列表之上**(不是最底部)。
- [ ] 计划内容正常加载;若失败有"下拉重试"提示且按钮置灰不可点(网络恢复后变实色可点)。
- [ ] 选不同 Day,内容切换正常。

## 7. 新用户 onboarding + 登录提示体系
- [ ] 全新安装:首启进入**问卷**(目标/年龄/熟悉度/图片页/主题/时长/提醒时间/通知)。
- [ ] 最后一屏是**登录页**(价值点 + Sign in / Maybe later);跳过或登录都能进 app。
- [ ] 登录成功后:**不再反复弹登录提示**;`sign_up` 只在首次登录上报。
- [ ] 未登录时,触发点(首个徽章 / 首条笔记/高亮 / day1 / 之后周期)会弹登录提示,但**3 天内最多 1 次、已登录不弹**。

## 8. 广告 🔴(美国瀑布流 + 频率)— 谨慎测,别误点
> dev build 下是 Google **测试广告**,点了不封号;正式 AAB 里是真广告,**自己别点**(会触发无效流量)。
- [ ] 美国地区(或把设备地区设为美国)用户:祈祷结束 / 计划结束能出插页,**不崩溃、不卡死**。
- [ ] **Day 0–2 温和**(只在祈祷/计划结束弹);**Day 3 起激进**(页面跳转每 3 次 + 热启动也弹)。
- [ ] 切到后台 ≥15s 再回前台 → 出一次开屏插页(仅 day≥3)。
- [ ] **广告展示间隔 ≥60 秒**(不会连弹)。
- [ ] 切走 app 的瞬间不会弹广告(前台判断)。
- [ ] 差网下不崩、不狂发请求;有网时正常恢复。
- [ ] 买了"移除广告"后:**完全不再出广告**。
