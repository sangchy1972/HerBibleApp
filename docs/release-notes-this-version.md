## 这一版实际做了什么（内部记录，不要贴进商店）

商店里说了的：

- **圣经问答**：每组 5 题，答错要重做直到全对
- **神秘卡片**：40 张，每 3 组抽一张，围绕 10 类真实的心事写成，7 语种
- **拼图画作**：24 幅公版古典圣经画作，按圣经年代排序，每 4 组拼完一幅，带画名 / 画家 / 30 词场景说明，7 语种
- **每日 3 组上限**：正好等于一天抽一张卡，所以「每天一张卡」是能被感知的节奏
- **收藏页**：卡片与画作分别独立成页，都挂在 Profile 下

商店里**没说**、但确实做了的：

- 题库全部答完后 quiz 自动从首页退场（题库扩容后自动恢复，无需迁移）
- 下午空档的功能推广弹窗（当天其他都做完、还没到晚祷时间才出现）
- 重做题目时的插屏广告
- 六轮审查修掉的 bug：4 处空白页、最后一张卡拿不到、SavedVerses 覆盖用户数据、3 条白屏路径
- 隐私政策补充了广告中介伙伴（Meta Audience Network / Liftoff）的披露

⚠️ **下一版必须处理**：题库只有 327 题 = 66 组，而集齐 24 幅画需要 96 组、40 张卡需要 120 组。
现在退场机制会让收藏永远停在 16/24 和 22/40。题库需要扩到 **600 题**才能全部可达。
见 `__tests__/quizLifecycle.test.ts` 的 "records the gap the bank still has to close"。
